# keepwarm

Мод для Claude Code: держит кэш промпта тёплым в сессии, где предстоят долгие перерывы. Аналог режима Idle из десктопного приложения, но работает и в VS Code, и в терминале.

Кэш основного разговора живёт час с последнего запроса (на подписке в пределах лимита). После этого первый ход пишет весь разговор заново, а это дорого. Мод за 5 минут до истечения часа отправляет пинг через `$.model.fork`: копию последнего запроса с просьбой «ответь точкой». Пинг читает разговор из кэша (≈0,1 цены ввода), продлевает его ещё на час и ничего не добавляет в переписку.

> Моды (function hooks) в Claude Code пока в раннем доступе. Если у вас их нет, плагин установится, но не загрузится.

## Установка

    claude plugin marketplace add als-studio/keepwarm
    claude plugin install keepwarm@keepwarm --scope user

## Использование

По умолчанию выключен. Включается только в текущей сессии:

- `/keepwarm on [часы]` — или попросите Claude «включи подогрев» (инструмент `keepwarm`);
- `/keepwarm off`, `/keepwarm status`, `/keepwarm now` — пинг сейчас, для проверки.

## Защиты

- пауза до следующего хода: после `/model` и сжатия (кэша для нового разговора ещё нет), если кэш уже остыл (компьютер спал), при разговоре меньше 20 тыс. токенов, после двух ошибок API подряд;
- остановка через 8 ч простоя (`/keepwarm on 12` — через 12, максимум 24);
- выключение, если пинг промахнулся мимо кэша (прочитал меньше, чем записал), и самопроверка на первом ходе после подогретого перерыва. Так же ловится 5-минутный кэш (API-ключ, оплата сверх лимита подписки) — там мод бесполезен.

Работает, пока открыт VS Code / терминал и компьютер не спит. Пинги расходуют лимит подписки: при разговоре на 150 тыс. токенов пинг ≈ 15 тыс. в час против ≈ 300 тыс. при холодном возврате.

## Лог

`~/.claude/keepwarm/<id сессии>.jsonl`: поля `read`/`write` — сколько пинг прочитал из кэша и записал. Удачный пинг: `read` в тысячи раз больше `write`. Состояние хранится в `$.store` мода по id сессии; записи старше 14 дней чистятся.
